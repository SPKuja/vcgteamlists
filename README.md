# VGC Team Lists

A polished, mobile-first Pokémon VGC team sheet builder.

## Product principles
- Looks polished and visual, not like a spreadsheet.
- Mobile-first and PWA-ready so it feels close to a native app.
- Generates clean team lists for printing and sharing.
- Pokémon search is never restricted by regulation.
- Game choice controls which fields are captured.

## Initial game presets
- Pokémon Champions
- Pokémon Scarlet / Violet
- Pokémon Sword / Shield
- Custom / Other

## Hosting
Static site deployed from `main` to DreamHost Shared Hosting through GitHub Actions.
